# EO - Eslam Osama

Personal portfolio for integrated business systems, websites and desktop applications.

## Run locally

Open `index.html` directly in a browser. No installation or build step is required.

For a local HTTP preview with Node.js installed, run `node server.cjs`, then open http://127.0.0.1:4317/.

## Features

- Arabic and English with RTL and LTR layouts.
- Dark and light themes with saved preferences.
- Responsive desktop, tablet and mobile layouts.
- Interactive system illustration and robot companion, respecting reduced-motion preferences.
- Project detail pages, image galleries, original-size viewing and keyboard navigation.
- Contact links and a live website link for El Nour Furniture.

## Projects

1. Flash Wash
2. EggTrade Desktop
3. El Nour Furniture
4. DRAX

Flash Wash and EggTrade use application screenshots. El Nour Furniture and DRAX use original visual materials from their websites, identified as website imagery rather than page screenshots. DRAX is presented as a portfolio concept without an external hosting link.

## Editing

- `app.js`: project data, bilingual content, routing and galleries.
- `system-hero.js` and `robot.js`: interactive illustrations.
- CSS files: layout, themes and section styling.
- `assets/`: optimized images, branding and favicon files.

Google Fonts are optional; system fonts provide an offline fallback. Video sections are intentionally omitted.
